# 🩺 Saúde e Higiene: Diagnósticos por IA e o Racismo Algorítmico

> Projeto acadêmico e web-app interativo focado no combate às disparidades raciais em sistemas automatizados de diagnósticos médicos e na promoção da auditoria humana contínua.

## 📌 Sobre o Projeto

O avanço da Inteligência Artificial (IA) no diagnóstico médico traz soluções promissoras para a saúde digital. No entanto, a sub-representação histórica de indivíduos pretos e pardos nos bancos de dados dermatológicos e clínicos faz com que modelos automatizados apresentem **taxas elevadas de falsos negativos e subestimação do risco** em pacientes de pele negra (fototipos Fitzpatrick IV a VI).

Este repositório contém uma aplicação web completa projetada para:
1. **Conscientizar** a comunidade acadêmica e médica sobre o racismo algorítmico na saúde.
2. **Demonstrar um Fluxo Prático de Contestação de Viés em 4 Etapas** (Resultado do Algoritmo ➔ Solicitação de Contestação ➔ Formulário com Anexo de Exames ➔ Confirmação com Protocolo).
3. **Simular um Painel de Auditoria Médica**, permitindo que médicos especialistas revisem laudos divergentes e re-treinem o modelo de IA.
4. **Oferecer um Quiz Educativo de 10 Perguntas** fundamentado na publicação da Universidade Federal do Maranhão (UFMA).

## 🚀 Como Executar o Projeto Localmente

Você pode rodar o projeto diretamente no seu navegador ou utilizar a extensão **Live Server** no **Visual Studio Code**:

1. **Clone este repositório:**
   ```bash
   git clone https://github.com/SEU-USUARIO/racismo-algoritmico-saude.git
   ```
2. **Acesse a pasta do projeto:**
   ```bash
   cd racismo-algoritmico-saude
   ```
3. **Abra no Visual Studio Code:**
   ```bash
   code .
   ```
4. **Execute no navegador:**
   - Abra o arquivo `index.html` diretamente em seu navegador, ou
   - Clique com o botão direito no `index.html` no VS Code e selecione **"Open with Live Server"**.
